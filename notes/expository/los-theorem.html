1Ultrafilters and Ultraproducts

Throughout, III is a nonempty index set.

Definition 1.1

An ultrafilter on III is a collection U\UU of subsets of III such that

  • ∅∉U\varnothing\notin\U∅∈/U;
  • if A,B∈UA,B\in\UA,B∈U then A∩B∈UA\cap B\in\UA∩B∈U;
  • if A∈UA\in\UA∈U and A⊆B⊆IA\subseteq B\subseteq IA⊆B⊆I then B∈UB\in\UB∈U;
  • for every A⊆IA\subseteq IA⊆I, exactly one of AAA and I∖AI\setminus AI∖A is in U\UU.

A collection satisfying the first three conditions, and containing III, is a filter.

Think of the sets in U\UU as the “large” sets, and of a property that holds on a set in U\UU as holding “U\UU-almost everywhere.” The last condition says that every subset of III is either large or has large complement. The first three conditions give a useful reformulation: a filter U\UU contains A∩BA\cap BA∩B if and only if it contains both AAA and BBB.

For a fixed i0∈Ii_0\in Ii0​∈I, the sets containing i0i_0i0​ form an ultrafilter, the principal ultrafilter at i0i_0i0​. If III is finite, every ultrafilter is principal; we will see that principal ultrafilters give nothing new. A family of subsets of III has the finite intersection property if every finite subfamily has nonempty intersection.

Lemma 1.2

Every family of subsets of III with the finite intersection property is contained in an ultrafilter. An ultrafilter is non-principal if and only if it contains every cofinite subset of III. In particular, if III is infinite, then every infinite S⊆IS\subseteq IS⊆I belongs to some non-principal ultrafilter.

Proof

The sets containing a finite intersection of members of the family form a filter. By Zorn's lemma it is contained in a maximal filter U\UU. If neither AAA nor I∖AI\setminus AI∖A were in U\UU, then A∩B≠∅A\cap B\ne\varnothingA∩B=∅ for every B∈UB\in\UB∈U, since otherwise B⊆I∖AB\subseteq I\setminus AB⊆I∖A would put I∖AI\setminus AI∖A in U\UU. The sets containing some A∩BA\cap BA∩B with B∈UB\in\UB∈U would then form a strictly larger filter, a contradiction. So U\UU is an ultrafilter.

If U\UU is principal at i0i_0i0​, it misses the cofinite set I∖{i0}I\setminus\{i_0\}I∖{i0​}. Conversely, if U\UU misses a cofinite set I∖FI\setminus FI∖F, then F∈UF\in\UF∈U for a finite set FFF. So {i0}∈U\{i_0\}\in\U{i0​}∈U for some i0i_0i0​, and then U\UU consists of the sets containing i0i_0i0​.

Finally, if SSS is infinite, then SSS together with the cofinite subsets of III has the finite intersection property, and any ultrafilter containing this family is non-principal.

When III is infinite, non-principal ultrafilters therefore exist, but no one can write one down explicitly: their existence uses the axiom of choice in an essential way.

2Łoś's Theorem

The definition of the ultraproduct only says how atomic formulas are evaluated: an equation or relation holds in ∏UMi\Uprod M_i∏U​Mi​ exactly when it holds in U\UU-almost every factor. Łoś's theorem says that the same is true of every first-order formula. In order to show that ∏UMi\Uprod M_i∏U​Mi​ has a first-order property, it is enough to check the property in a large set of factors. The proof is an induction on formulas, and the ultrafilter axioms are exactly what each step needs: closure under intersection handles conjunction, the dichotomy between AAA and I∖AI\setminus AI∖A handles negation, and the axiom of choice supplies witnesses for existential quantifiers. At the end of the section we specialize to ultrapowers, where Łoś's theorem gives elementary embeddings M→MI/UM\to M^I/\UM→MI/U.

3Applications of Łoś's Theorem

The applications in this section all follow one pattern: we choose an ultrafilter so that the property we want holds on a large set of factors, and Theorem 2.1 then transfers that property to the ultraproduct, or from the ultraproduct back to the factors. In Section 3.1 the factors are models of finite pieces of a theory, and the ultraproduct is a model of the whole theory. In Section 3.2 the factors are fields of characteristic ppp for varying ppp, and the ultraproduct is a field of characteristic 000, which lets us move statements between the two settings.

3.1Compactness

The compactness theorem is one of the fundamental results of mathematical logic, and much of model theory is built on it. The compactness theorem says that whether a first-order theory has a model can be decided one finite piece at a time. The usual proofs go through Gödel's completeness theorem or a Henkin construction, which builds a model out of the syntax of the theory. Łoś's theorem gives a more direct route: the model is an ultraproduct of models of the finite pieces, with an ultrafilter chosen so that each sentence of the theory holds in a large set of factors.

If every finite subset of a first-order theory TTT has a model, then TTT has a model.

4Pitfalls

Theorem 2.1 makes ultraproducts look like they inherit everything from their factors, but there are limits. We collect three of them here. Only first-order properties transfer, an ultraproduct of finite structures need not be finite, and different ultrafilters can give ultraproducts with different theories.

4.1It is first-order only

Theorem 2.1 applies to first-order formulas, whose quantifiers range over elements of the structure. Properties that quantify over subsets or ideals, or that need an unbounded disjunction such as “for some kkk,” usually do not transfer.

Example 4.1 (Completeness of R\RRR fails)

The ultrapower ∗R{}^*\RR∗R of Section 2.2 is not Dedekind complete. The set of infinitesimals, the xxx with ∣x∣<r|x|<r∣x∣<r for every real r>0r>0r>0, is nonempty and bounded above by 111. Suppose sss were its least upper bound. The positive infinitesimal ε=[(1/n)n≥1]\varepsilon=[(1/n)_{n\ge1}]ε=[(1/n)n≥1​] of Section 2.2 lies in this set, so s≥ε>0s\ge\varepsilon>0s≥ε>0.
